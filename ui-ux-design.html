UNDERSTANDING DESIGN

UI Design vs UX Design.

Both disciplines work together to create digital products that look good and are easy to use.

UI Design

User Interface design focuses on the visual elements users interact with on a website or application.

  • Colors and Typography
  • Buttons and Icons
  • Layouts and Spacing
  • Visual Components

UX Design

User Experience design focuses on how people interact with a product and how easily they complete their tasks.

  • User Research
  • User Journeys
  • Information Architecture
  • Usability and Navigation
